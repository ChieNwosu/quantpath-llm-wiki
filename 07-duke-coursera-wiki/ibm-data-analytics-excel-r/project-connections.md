## How Phase 1 Connects to the IBM Certificate

Phase 1 of the QuantPath Mortgage Rate Intelligence Stack is an applied learning project that demonstrates Excel analytics skills aligned with the IBM Data Analytics with Excel and R Professional Certificate.

**What it demonstrates:**
- Real-world Excel financial modeling with public data
- Dashboard design for non-technical stakeholders
- Structured workbook architecture (data → inputs → models → outputs)
- Financial function proficiency (PMT, PV, CUMIPMT, PPMT, IPMT)
- Decision-support design, not just calculation

**What it is not:**
- An official IBM capstone project
- A graded assignment
- A submission to IBM or Coursera

---

## How Phase 2 Will Connect to the IBM Certificate

Phase 2 (planned) will extend the project into R-based time-series analysis, connecting to the R modules of the certificate.

**Planned connections:**
- Data loading and cleaning in R → Data Analysis with R module
- Time-series visualization → Data Visualization in R module
- Statistical analysis (stationarity, rolling stats) → Data Analysis with R module
- R Markdown reporting → Data Analysis with R module

---

## How Phase 2 Connects to NCCU Applied Time Series Analysis

Phase 2 also connects to the Applied Time Series Analysis course at North Carolina Central University.

**Course-relevant methods:**
- Stationarity testing (ADF, KPSS) — [[stationarity-testing]]
- ARIMA modeling (via `TSA` package)
- ACF/PACF analysis
- Seasonal decomposition (via `uroot`)
- Nonlinear smoothing (via `locfit`)

When describing this project in a portfolio, resume, or LinkedIn context:

> This project connects applied Excel-based analytics, financial modeling, and R-focused learning from IBM's Data Analytics with Excel and R Professional Certificate with my broader QuantPath analytics portfolio.
