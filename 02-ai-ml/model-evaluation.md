# Model Evaluation

**Summary**: Model evaluation measures how well a machine learning model performs on unseen data.

**Sources**: ML coursework, scikit-learn docs

**Last updated**: 2026-05-05

---

## Plain-English Explanation
Model evaluation tells you if your model is actually good or just memorizing the training data.

## Why It Matters
Without evaluation, you cannot trust predictions or deploy models in real-world applications.

## Technical Breakdown
Common metrics:
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Example
Evaluating a classification model predicting income:
- Accuracy: 84%
- F1 Score: 0.67
