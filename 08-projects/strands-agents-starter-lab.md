## Business or Research Question

Can Kiro use the Strands MCP server to retrieve live SDK documentation and scaffold a working Python agent from scratch? This lab tests the Kiro + MCP + Strands Agents SDK integration as a foundation for future QuantPath OS agentic components.

---

## Technical Workflow

1. Kiro connects to the Strands MCP server.
2. MCP server provides access to Strands Agents SDK documentation.
3. Kiro searches the documentation and generates setup steps.
4. A basic Python agent is scaffolded using the Strands Agents SDK.
5. Agent is run in a Python virtual environment managed by `uv`/`uvx`.

**What worked**: Kiro successfully used the Strands MCP server to search documentation and generate README-ready setup steps.

---

## Key Concept

The MCP server is the bridge between Kiro and external documentation/tools. The Strands Agents SDK is the Python package used to define and run agents. These are two distinct layers:

- **MCP** = tool access protocol (how Kiro reaches external capabilities)
- **Strands Agents SDK** = agent runtime (how Python agents are built and executed)
