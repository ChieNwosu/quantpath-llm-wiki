# CFPB Complaint Dashboard

**Summary**: A data analytics project analyzing consumer complaints using AWS tools.

**Sources**: CFPB dataset, AWS architecture planning

**Last updated**: 2026-05-05

---

## Plain-English Explanation
This project analyzes consumer complaints related to credit cards and fees to identify trends and insights.

## Why It Matters
It demonstrates real-world data analytics using cloud tools.

## Technical Breakdown
- Data stored in [[aws-s3]]
- Queried using SQL (Athena)
- Potential visualization via QuickSight

## Example
Filtered complaints:
- State: NC
- Product: Credit Card
- Issue: Fees or interest

## Portfolio Connection
Core project demonstrating SQL + AWS + analytics skills.

## Interview Explanation
“I built a cloud-based analytics workflow using S3 and SQL to analyze financial complaints and generate insights.”
