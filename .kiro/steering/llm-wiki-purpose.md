# QuantPath LLM Wiki — Purpose and Goals

## What This Is

The QuantPath LLM Wiki is a personal, AI-assisted knowledge base maintained in Obsidian. It is a structured Markdown knowledge graph inspired by Andrej Karpathy's LLM Wiki pattern, customized for Chiemela Nwosu's learning path across AI/ML, data analytics, SQL, AWS/cloud, quantitative finance, Databricks, and Duke/Coursera coursework.

## Primary Goals

1. **Learning infrastructure** — Build a dense, interlinked, source-backed thinking system that compounds over time.
2. **Portfolio foundation** — Convert learning into GitHub-ready project documentation, README files, and interview talking points.
3. **RAG deployment** — Prepare the vault for ingestion into an Amazon Bedrock Knowledge Base for AI-assisted retrieval.
4. **QuantPath OS seed** — This wiki is the knowledge layer that will eventually power QuantPath OS: an AI-powered learning and research operating system.

## What the Wiki Is Not

- Not a tag-heavy Notion database
- Not a copy-paste repository of course transcripts
- Not a public blog (yet)
- Not a replacement for hands-on project work

## Guiding Principle

> Structure first → source discipline second → useful notes third → public exports fourth → agent automation fifth.

The human curates sources, validates outputs, and decides what becomes public. Kiro helps structure, connect, verify, and convert knowledge into long-term value.

## Domains Covered

- AI/ML: concepts, model evaluation, RAG, embeddings, guardrails, prompt engineering
- Data: SQL, analytics, data modeling, pipelines, ETL/ELT, data lakes, warehouses
- AWS/Cloud: S3, Glue, Athena, QuickSight, IAM, Bedrock, Lambda, OpenSearch
- Quant Finance: returns, volatility, risk modeling, portfolio optimization, DeFi, time series
- Databricks: notebooks, Spark, Delta Lake, SQL, Python/R workflows
- Duke/Coursera: R programming, statistics, DeFi, finance specializations
- Agentic AI: MCP, Strands Agents SDK, Kiro, Amazon Bedrock Agents
- Projects: CFPB dashboard, QuantPath OS, Bedrock RAG, ML classification/regression

## Future RAG Layer

Notes should be:
- Concise and self-contained
- Factually grounded with source citations
- Structured with clear headings for chunking
- Free of long AI-generated prose dumps

This supports future embedding and retrieval via Amazon Bedrock Knowledge Bases.
