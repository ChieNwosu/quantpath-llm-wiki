# Databricks

**Summary**: A cloud-based platform for data engineering, analytics, and machine learning.

**Sources**: Databricks docs, personal exploration

---

## Plain-English Explanation
Databricks is like a workspace where you can write Python, R, and SQL to analyze data.

## Why It Matters
It unifies data engineering and machine learning workflows.

## Technical Breakdown
- Built on Apache Spark
- Supports notebooks
- Integrates with cloud storage

## Portfolio Connection
Will be used for QuantPath workflows.
